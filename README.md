# StoryVerse 3D (three.js)

Interactive Pixar-like storytelling playground for kids, built with three.js.

## Story options
1. Toy Rescue Rocket
2. Ocean Lantern Parade
3. Cloud Kingdom Race
4. Forest Firefly Quest
5. Space Library Guardians

## Run locally
Use any static server. Example:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Controls
- Choose a story from the dropdown
- Or click story chips to switch experiences
- Drag to orbit camera
- Scroll to zoom
